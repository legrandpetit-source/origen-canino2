# 🐾 Origen Canino - E-Commerce Platform

![Origen Canino](https://origencanino.cl/favicon.ico)

## 📌 Descripción del Proyecto
**Origen Canino** es una plataforma de comercio electrónico moderna y escalable construida desde cero (End-to-End) diseñada específicamente para la venta de alimento natural para perros. Cuenta con una interfaz de cliente enfocada en la conversión y un completo Panel de Administración (Backoffice) para la gestión logística y financiera de la tienda.

## 🚀 Características Principales

### 🛒 Experiencia de Cliente (Frontend)
*   **Calculadora de Raciones:** Un algoritmo interactivo que calcula la porción exacta de comida requerida basándose en la edad, peso y nivel de actividad del perro.
*   **Catálogo Dinámico & Carrito:** Experiencia de compra fluida con manejo de estados globales.
*   **Diseño Responsive:** UI/UX cuidadosamente diseñada con **Tailwind CSS** para adaptarse perfectamente a cualquier dispositivo móvil o de escritorio.

### ⚙️ Panel de Administración (Backend/Backoffice)
*   **Gestión de Despachos (Dispatch Manager):** Control total sobre el estado de las entregas y zonas de reparto.
*   **Manejo de Recetas:** Administración de productos e ingredientes directamente desde la plataforma.
*   **Finanzas (Finance Manager):** Dashboard para el control de ingresos, ventas y métricas clave del negocio.

## 🛠️ Stack Tecnológico

*   **Frontend:** React.js, Vite, Tailwind CSS, Context API.
*   **Backend:** Python, FastAPI.
*   **Arquitectura:** RESTful API, Componentes Modulares (JSX).
